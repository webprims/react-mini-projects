# React Mini Projects

A practical collection of beginner-friendly React examples and mini projects maintained by **WebPrims**.

The goal is simple: learn React by building small, focused projects instead of only reading theory.

## What you'll learn

- Components and JSX
- Props
- `useState`
- `useEffect`
- Forms and controlled inputs
- Conditional rendering
- Lists and keys
- Fetching API data
- Basic reusable components

## Projects

```text
react-mini-projects/
├── 01-counter/
├── 02-user-card/
├── 03-todo-list/
├── 04-form-example/
├── 05-api-fetch/
└── 06-theme-toggle/
```

Each folder contains a focused example that can be copied into a standard React/Vite project.

## Quick start

Create a Vite React app:

```bash
npm create vite@latest my-react-app -- --template react
cd my-react-app
npm install
npm run dev
```

Then replace `src/App.jsx` with one of the example files in this repository.

## Learning approach

Run the example first, then change it. Add one feature of your own before moving to the next project. Small experiments are where React starts to make sense.
